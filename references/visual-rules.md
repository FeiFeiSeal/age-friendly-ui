# Visual rules

本檔皆為 **Age-friendly Recommendation**。若涉及正式門檻，另依 [wcag-2.2](wcag-2.2.md) 分類與驗證。

| 主題 | 判斷與具體改善 | 驗證 |
| --- | --- | --- |
| Typography | 內文可從約 18 CSS px 作設計起點，依中文字形、字重、裝置和內容密度調整；不用一種大字級填滿整頁。支援使用者縮放；避免過細字重與截斷關鍵金額。 | 讀日期、金額、相似字元；放大後檢視換行與功能。18px 不是 WCAG 最小字級。 |
| Contrast | 關鍵文字避免貼近最低門檻的脆弱配色，評估細字與環境光；高飽和不代表高對比。 | 使用實際色值量測；截圖僅標風險或估值。 |
| Color dependency | 讓狀態同時有短標籤、圖示形狀或位置線索，避免只剩紅綠點。 | 不靠顏色能否讀出待處理／完成／失敗。涉及 SC 1.4.1 另核對。 |
| Component boundary | 在辨識困難處用清楚底色、邊界或留白表達互動範圍；保留熟悉控制項的外觀，避免過淡細線。 | 讓使用者指出可點區；不是每個 card 加粗框，也無 WCAG 固定 border 寬度。 |
| Hierarchy | 同一任務區突出當下主操作，次操作降低權重但仍可辨識；重要狀態靠近內容。 | 讓使用者說出下一步；不要假定整頁只能有一個 CTA。 |
| Spacing | 用群組間距分離任務與危險操作，用群組內接近表達關聯；避免全頁放大間距導致來回捲動。 | 比較找到欄位／按鈕的路徑與誤觸；不捏造通用最小 gap。 |
| Scroll visibility | 提供延續內容線索、清楚區段標題；避免關鍵動作藏在難察覺的內部捲軸；保留捲動位置。 | 查長內容、窄視窗、放大後下方內容能否被發現；固定 footer 不遮欄位及 focus。 |

Disabled 不代表應消失到無法辨識；可提供可讀的停用原因和解除條件。Inactive contrast 的 WCAG 例外與此建議分開判斷。

原則依據：[Older users 情境](older-users.md)。具體字級與版面選擇是本 skill 的設計起點，並非 W3C 統一指定值。
