# Older users：設計出發點

本檔是情境與設計判斷，不是 WCAG 新增要求。

[W3C WAI Older Users](https://www.w3.org/WAI/older-users/) 說明年齡相關的視覺、精細動作、聽覺、記憶及注意力變化與無障礙需求重疊。這不代表所有長者都有相同能力、設備或數位經驗。

先由輸入確認主要任務、使用裝置、輸入方式、熟悉度、使用頻率及錯誤後果。缺少資料時明列假設，先 review 已知部分，不必等完整 persona。

以下是本 skill 將 inclusive design 思路轉成操作介面判斷的建議：

| 使用障礙 | 應追問的任務問題 | 優先方向 |
| --- | --- | --- |
| 近距閱讀與低對比辨識困難 | 能辨識金額、日期、狀態與欄位嗎？ | 清楚字形、有效對比、可放大與合理分組 |
| 精細動作下降、手部不穩 | 是否容易按到隔壁或在拖曳途中失敗？ | 可辨識點擊區、適當間距、非拖曳替代 |
| 短期記憶負擔 | 下一頁是否要求回想上一步資料？ | 在需要處重現摘要、保留輸入與選擇 |
| 注意力負擔 | 是否被大量等權 CTA 或自動變動打斷？ | 明確主要動作、安定版面、適時而非過量提示 |
| 陌生 pattern 與重新學習 | 改版是否搬動熟悉功能或改名？ | 優先局部修正、維持命名與流程 |
| 狀態／下一步不明 | 等待時會重複送出嗎？做錯能返回嗎？ | 可理解的進度、結果、下一步及恢復入口 |

對高齡使用者的影響要連到具體任務，不只寫「提升可及性」。例如：「未顯示已儲存的時間，使用者可能反覆點擊送出，產生重複申請」。

[W3C COGA：Making Content Usable](https://www.w3.org/TR/coga-usable/) 是補充性 guidance，支持清楚目的、熟悉操作及減少記憶負擔的方向；它不是 WCAG 合規門檻。本文的具體 UI 選擇仍需目標使用者驗證。

測試應涵蓋不同熟悉度與輸入方式的高齡參與者，觀察任務完成、誤操作、尋找下一步與錯誤恢復。視覺模擬或自動檢查不能取代實際使用。

來源核對：2026-10-06。WAI 的較早研究可說明需求背景；WCAG 2.2 數值以當前正式 SC 為準。
